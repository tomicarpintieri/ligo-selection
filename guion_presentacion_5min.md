|---:|---|---|
| 0:00–0:20 | Título | «Una detección no es una muestra neutral del universo: LIGO oye mejor algunas fusiones que otras.» |
| 0:20–1:05 | Problema | Masa, distancia, orientación y posición en el cielo determinan la detectabilidad. Eso sesga el catálogo observado. |
| 1:05–2:00 | Resultado principal | Para GW150914, el horizonte es el mejor caso. El factor horizonte/rango es 2.2649; como el volumen escala como la distancia al cubo, ignorar geometría altera mucho los conteos. |
| 2:00–2:55 | Validación | El pipeline recupera GW150914 en H1 y L1: SNR 19.81 y 13.54, con el retardo de −7.08 ms. La waveform coincide con la referencia LAL (match 1.000). |
| 2:55–3:40 | Aprendizaje | Lo importante fue construir una cadena reproducible: datos verificados, pruebas automáticas y limitaciones explícitas. TaylorF2 inspiral-only subestima sistemas pesados. |
| 3:40–4:15 | Cierre | La selección debe modelarse antes de inferir poblaciones. El siguiente paso es una campaña de inyecciones sobre datos reales. |
